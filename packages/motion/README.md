# @stackvibe-studio/motion

Motion primitives and reveal patterns for premium product experiences.

## Highlights

- Scroll-aware reveal sections
- Spotlight cards with soft glow lighting
- Clean text reveal utilities
- New in v0.2.0: FadeInSection for storytelling and landing pages

## Install

```bash
npm install @stackvibe-studio/motion
```

## Example

```tsx
import { FadeInSection, SpotlightCard } from '@stackvibe-studio/motion';

export function Example() {
  return (
    <FadeInSection>
      <SpotlightCard className="p-6">Premium motion without the bloat.</SpotlightCard>
    </FadeInSection>
  );
}
```
